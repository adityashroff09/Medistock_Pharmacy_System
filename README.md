# MediStock – Pharmacy Management System

MediStock is a web-based Pharmacy Management System developed as a B.Tech CSE academic project. It helps manage medicine inventory, track stock levels and expiry dates, generate bills, and maintain sales records.

### Features
- Medicine inventory management
- Stock and expiry tracking
- Low-stock alerts
- Billing system
- Sales history
- Medicine search and filtering
- Admin and staff login interface

### Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

### Deployment
The project can be hosted using GitHub Pages and accessed through a web browser.

### Disclaimer
This project is developed for educational purposes. Sample medicine details and prices are for demonstration only.
